📱 Tip: Open this page on your phone (or use a QR code) so the plantly:// links open the app.

How to test

  • Android: Install the dev/preview build, then tap Click me. A system dialog may ask which app should open the link — choose Plantly.
  • iOS: Install the dev build, then tap Click me. The app should open directly on the plant #1 detail screen.
  • Expected result: The app opens the plants/1 screen. The action=water link also waters the plant automatically.
  • If nothing happens, make sure the app was built with the plantly scheme (it is set in app.json) and that the build includes native project files.
